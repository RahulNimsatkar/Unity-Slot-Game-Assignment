A classic 3-reel slot machine built in **Unity 6 (6000.6.5f1)** with a WebGL build target.

## 🎮 How to Play

1. **Set your bet** using the ◀ / ▶ arrows (10 / 50 / 100 credits)
2. **Pull the lever** (click it) or press the **SPIN** button
3. Watch the reels spin with smooth elastic-bounce animations
4. **Win conditions:**
   - 🍒🍒 Two Cherries → **×2** your bet
   - 🍒🍒🍒 Three Cherries → **×5**
   - 🔔🔔🔔 Three Bells → **×10**
   - 📊📊📊 Three Bars → **×20**
   - 7️⃣7️⃣7️⃣ Three Sevens → **×50 JACKPOT!**
5. **Bonus:** ~12% chance of a **free spin** on any winning result
6. When credits hit 0, a popup asks to refill — choose Yes to continue

## 🧪 How to Test & Run the Project

Evaluators can test the project using either of the two methods below:

### ⚡ Method 1: Instant Browser Play via WebGL (Recommended — No Unity Install Needed)

A complete, fully functional WebGL production build is pre-compiled and included directly in `Build/WebGL/`.

1. Open a terminal in the root `SlotGame` folder and start a local HTTP server:
   ```bash
   python -m http.server 8080 --directory Build/WebGL
   ```
   *(Or using Node.js: `npx serve Build/WebGL`)*

2. Open your browser and navigate to:
   ```
   http://localhost:8080
   ```
3. Play the game immediately in your browser!

## 🏗️ Architecture & Design Decisions

### Separation of Concerns
- **Core logic** (`SlotRNG`, `PayTable`, `Wallet`) is pure C# with no Unity dependencies — unit-testable outside the engine
- **View layer** (`GameUI`, `PopupController`) only *observes* through C# events, never mutates game state directly
- **Orchestrator** (`SlotMachineController`) owns the spin flow and connects everything

### Fair RNG
- All outcomes are determined **before** animations begin (line 122 of SlotMachineController)
- Weighted random: Seven (10%), Bar (20%), Bell (30%), Cherry (40%)
- Seed combines `Environment.TickCount` with a GUID hash for unpredictability

### Reel Animation (the hard part)
Four-phase coroutine in `Reel.cs`:
1. **Accelerate** — SmoothStep from 0 to max speed
2. **Cruise** — constant velocity, staggered per reel for drama
3. **Land** — cubic ease-out to the exact target position (no snapping)
4. **Bounce** — elastic overshoot via `sin(π·t)` for satisfying weight

Symbols recycle: when one exits the bottom, it teleports to the top with a new random sprite, creating the illusion of an infinite reel strip.

### Auto-Generated Assets
- **Sounds:** 7 clips synthesized from math (sine/square/sawtooth waves + noise) — zero licensing risk
- **Scene:** Built entirely by `SceneBuilder.cs` — no manual drag-and-drop needed

### Bonus Features (beyond the assignment)
| Feature | Description |
|---------|-------------|
| **Free Spin** | 12% chance on any win; auto-plays after 1.4s delay |
| **Two-Cherry Bonus** | Exactly 2 cherries = ×2 consolation prize |
| **Lever Interaction** | Click the lever (not just a button) to spin |
| **Motion Blur** | Symbols stretch vertically proportional to speed |
| **Elastic Bounce** | Rubber-band overshoot when reels land |
| **Pop-in Popup** | Back-out easing animation on the bankruptcy dialog |
| **Procedural Audio** | Retro casino blips generated at build time |

## 🎵 Sound Effects

All 7 clips are procedurally synthesized — no external audio files needed:

| Clip | Description | Technique |
|------|-------------|-----------|
| `click.wav` | UI button click | Square + sine, fast exponential decay |
| `lever.wav` | Mechanical lever pull | Pitch sweep down + noise burst |
| `reel_stop.wav` | Reel landing thud | Low sine + high-freq click transient |
| `spin_loop.wav` | Continuous reel hum | Two detuned sawtooths with fade edges |
| `win.wav` | Win fanfare | 4-note ascending arpeggio |
| `jackpot.wav` | Jackpot celebration | 7-note extended arpeggio |
| `lose.wav` | Loss sting | Descending "wah-wah" sine sweep |

## 🔧 Technical Notes

- **Unity version:** 6000.6.5f1 (Unity 6 LTS)
- **Render pipeline:** Built-in (no URP/HDRP — keeps WebGL simple)
- **UI system:** Unity UGUI (Canvas + RectTransform)
- **Reference resolution:** 1080×1920 (portrait), scales via `CanvasScaler` MatchWidthOrHeight
- **WebGL compression:** Disabled (for maximum compatibility without server config)
